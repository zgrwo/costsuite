## 1. 快速开始

### 1.1 安装

1. 从 IT 部门获取 `BomAddIn.zip` 安装包
2. 解压到本地文件夹（如 `C:\Program Files\BomAddIn\`）
3. 双击 `BomAddIn-AddIn.xll`（64 位）或 `BomAddIn-AddIn64.xll`
4. Excel 启动后，Ribbon 菜单栏出现 **「BOM Suite」** 标签页 → 安装成功

> ⚠️ 若提示安全风险，请联系 IT 将此 XLL 文件加入白名单。

### 1.2 首次登录

1. 点击 Ribbon → **BOM Suite** → **登录**
2. 输入用户名和密码（由管理员分配）
3. 登录成功后，任务窗格显示 "在线 / 已同步"

## 2. 功能指南

### 2.1 BOM 展开

**场景**: 查看一个产品的完整物料清单。

1. 在 Excel 任意单元格输入：
   ```
   =BOMEXPAND("物料编码")
   ```
2. 按 Enter：
   - **Excel 365**: 结果自动展开为一个表格
   - **Excel 2016/2019**: 选中足够大的区域（如 A1:F50），按 `Ctrl+Shift+Enter`

**展开结果包含**：层级、物料编码、描述、用量、单位、来源（自制/外购）

**可选参数**:
```
=BOMEXPAND("物料编码", "2026-06-01")        ← 查看 6 月 1 日时的 BOM
=BOMEXPAND("物料编码", , "Draft")            ← 只看草稿版本
```

详细语法见 [api-reference.md §3.1](./api-reference.md#31-bomexpand)

---

### 2.2 差异分析

**场景**: 比较两个 BOM 版本之间的变化。

#### 通过公式

```
=VARIANCECHECK("BOM-V12", "BOM-V13")
```

返回差异摘要：新增了什么、删除了什么、用量变了多少。

#### 通过仪表盘

1. Ribbon → **BOM Suite** → **仪表盘**
2. 选择「差异分析」面板
3. 选择基准版本和对比版本
4. 点击「比较」

仪表盘会以图表形式展示：
- 价格趋势变化（折线图）
- 库存水位变化
- 预警触发情况

---

### 2.3 数据同步

**自动同步**: 插件在后台定时拉取 ERP 最新数据（物料、价格、库存、订单）。

**手动同步**:
1. Ribbon → **BOM Suite** → **同步**
2. 或点击任务窗格中的「手动同步」

**同步状态标识**:

| 状态 | 含义 |
|------|------|
| 🟢 在线 / 已同步 | 数据是最新的 |
| 🔄 同步中... | 正在拉取数据，请稍候 |
| 🟡 网络断开 / ERP 同步暂停 (更新于: ...) | 网络断开，ERP 同步暂停。可查看和编辑本地数据。 |
| 🔴 离线 / 缓存过期 | 网络断开且缓存超过 24 小时 |

---

### 2.4 ERP 同步暂停（离线模式）

当网络断开时，插件自动切换为 **ERP 同步暂停**模式：

- ✅ 可以查看和编辑数据（SQLite 本地主库始终可读写）
- ✅ 可以使用所有 UDF 函数
- ✅ 可以创建本地快照
- ❌ 不能与 ERP 同步数据
- ❌ 不能提交在线审批（本地操作不受影响）

网络恢复后，插件自动恢复 ERP 同步并上传本地变更。

---

### 2.5 仪表盘

Ribbon → **BOM Suite** → **仪表盘** 打开独立窗口。

| 面板 | 显示内容 |
|------|---------|
| **KPI 概览** | 物料总数、活跃 BOM 数、待审批数、触发预警数 |
| **差异趋势** | 近 12 个月价格/库存差异变化曲线 |
| **预警列表** | 当前所有触发的预警（按严重级别排序） |
| **BOM 结构树** | 选中物料的完整 BOM 层级树 |

**导出图表数据**: 仪表盘每个面板右上角有「导出到 Excel」按钮，将当前图表数据写入活动工作表。

---

### 2.6 数据快照

**场景**: 保存当前所有数据的完整副本，用于日后对比或审计。

**自动快照**: 插件每次启动时自动创建「每日快照」。

**手动快照**:
1. Ribbon → **BOM Suite** → **任务窗格** 打开右侧任务窗格
2. 点击「创建手动快照」
3. 快照包含：物料主数据、BOM 结构、版本状态、价格记录、库存记录

**快照存储**: 所有快照保存在本地 SQLite 数据库中，默认保留 90 天。

---

### 2.7 BOM 审批工作流

**状态流转**: `Draft → PendingReview → Approved → Released → Obsolete`

| 操作 | 执行角色 | 说明 |
|------|---------|------|
| 提交审批 | Analyst / Admin | Draft → PendingReview |
| 审批通过 | Admin | PendingReview → Approved |
| 审批拒绝 | Admin | PendingReview → Rejected |
| 重新提交 | Analyst | Rejected → Draft |
| 发布版本 | Admin | Approved → Released |
| 废弃版本 | Admin | 任意状态 → Obsolete |

所有审批操作自动记录到审计日志（操作人、时间、状态变化）。

---

### 2.8 审计日志

所有增删改操作自动记录：
- 操作人、操作时间
- 操作类型（CREATE / UPDATE / DELETE / APPROVE / REJECT）
- 变更前后的数据（JSON 格式）
- 可通过 Ribbon → 仪表盘查看操作历史

## 3. 常用函数速查

| 我想做什么 | 公式 |
|-----------|------|
| 展开产品的 BOM | `=BOMEXPAND("物料编码")` |
| 查看 BOM 的总成本 | `=BOMCOST("物料编码")` |
| 查某个供应商的报价 | `=PRICELOOKUP("物料编码", "供应商编码")` |
| 查当前库存 | `=INVENTORYQTY("物料编码")` |
| 比较两个版本的差异 | `=VARIANCECHECK("BOM-V12", "BOM-V13")` |
| 检查物料是否有预警 | `=ALERTCHECK("物料编码")` |
| 查物料在途订单 | `=ORDERSTATUS("物料编码")` |
| 查看同步状态 | `=SYNCSTATUS()` |

> 完整语法见 [api-reference.md](./api-reference.md)

## 5. 故障排查

### 常见问题

| 症状 | 可能原因 | 解决方法 |
|------|---------|---------|
| Ribbon 没有 "BOM Suite" | 插件未加载 | 重新双击 `.xll` 文件；检查 Excel 禁用项目列表 |
| `#NAME?` 错误 | 插件未加载或函数名拼错 | 检查函数名是否全大写（`BOMEXPAND` 不是 `BomExpand`） |
| `#N/A` 错误 | 物料编码不存在 | 确认编码是否正确；检查是否有权限查看 |
| `#REF!` 错误 | 同步数据格式不兼容 | 检查 ErpAdapter 版本是否与插件版本匹配 |
| 仪表盘打不开 | .NET 运行时版本过低 | 运行 `BomAddIn.Diagnostic.exe` 检查环境 |
| 同步一直转圈 | 网络连接或 ERP 服务问题 | 等待 5 分钟自动重试；手动点同步；联系 IT |
| BOM 展开只有部分数据 | Excel 2016 数组公式限制 | 升级 Excel 365，或用 `Ctrl+Shift+Enter` 选中更大区域 |

### 诊断工具

运行 `BomAddIn.Diagnostic.exe`（位于安装目录），可自动检查：
- .NET 版本
- Excel 版本与位数
- 数据库连接
- 网络连通性
- 权限状态

将诊断结果截图发送给 IT 支持。

## 6. 数据安全

| 措施 | 说明 |
|------|------|
| 传输加密 | 所有与 ERP 服务器的通信使用 TLS 1.2+ 加密 |
| 存储加密 | 价格数据使用 AES-256 加密存储 |
| 密码保护 | 密码使用 BCrypt 哈希，不可还原 |
| 审计日志 | 所有数据修改操作记录操作人、时间、内容 |
| 离线缓存 | 本地 SQLite 缓存文件受 Windows 文件权限保护 |
| 价格脱敏 | Viewer 角色查看价格时仅显示 `****` |
